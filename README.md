# DSA practice environment

A small C++ and Python workspace for solving DSA problems with file-based input
and output.

## Quick start

1. Edit `practice/scratch/run.py` or `practice/scratch/run.cpp`.
2. Add a header at the top using `<topic>: <title>`.
3. Put test input in `practice/input.txt`.
4. Run `./run`.

Examples:

```python
# Recursion: Problem 8
```

```cpp
// Arrays: Two Sum
```

These are saved as `practice/solutions/python/recursion/problem_8.py` and
`practice/solutions/cpp/arrays/two_sum.cpp`. Running the same solution again
overwrites it.

Use `./run py` or `./run cpp` to select a language explicitly. See
`practice/README.md` for the full workflow.
